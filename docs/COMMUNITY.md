# 鲸声守望：DSH 社区讨论环境巡查插件（实验版）

我想号召大家共同维护社区讨论与创作环境，因此做了“鲸声守望”，一个从 DSH 侧栏打开的小红书内容巡查插件，欢迎试用和讨论。

它能按关键词或指定链接读取网页版实际展示的正文、评论、上级回复及配图，使用 DSH 已配置的大模型理解语境，展示“可疑”或“其它”、原文和判断依据。需要时可以使用支持图片的模型读取配图。普通爱好者只需查看结果，点击“已阅”整理列表；有 Agent 预设，也能通过自然语言发起同样的任务。

规则全文公开且可修改，关注七类行为：侮辱性人身攻击及谐音、群体不尊重或地图炮、普通创作区引战、牵连无关角色或圈子、威胁与隐私侵扰、骚扰报复动员、造谣歪曲或冒充挑拨。对不同立场采用相同标准，区分尖锐作品批评、引用反驳和实际攻击。插件不判断人的圈籍与忠诚度，也没有自动举报功能。

背景页提供36篇可见材料的整理与来源索引，可自行选择启用，也能让模型重新阅读用户选择的文章、生成替代背景。整理摘要、来源与判断规则可以查看和修改。来源中的指控保留作者归属，不直接当作已核实事实。

目前0.6.3已在 Linux、Node 24、DSH Web 0.2.0-rc.2 验证安装及侧栏入口，65项程序检查通过。提供32条人工编写样例和可导出的评估报告；这些样例及程序检查不能证明真实内容准确率。最新版本修复过一次实际漏判：复核把“没点名个人”错误地当作否决群体不尊重的理由。定向重试后两轮判断一致，但完整实模评估和其他系统兼容性仍待扩展。

采集范围是少量搜索结果及已加载评论；App专属内容列为未读取，登录或验证由用户处理。视频和音频未识别，页面改版可能导致读取失败。文字、相关背景及需要读取的配图会发送给所选模型服务；记录和独立采集浏览器登录状态保存在本机。模型有调用费用，默认每轮最多55条内容分析，疑似问题另做一次复核，看图另计。

欢迎反馈安装与使用问题、原文或回复关系的读取错误、模型误报与漏报。请附版本、脱敏原文与必要上下文、实际结果及你认为的依据，不要公开密钥、Cookie、浏览器目录或整份巡查数据。
