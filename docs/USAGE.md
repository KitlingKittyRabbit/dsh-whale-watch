# 鲸声守望使用手册

[返回首页](../README.md) · [版本更新](CHANGELOG.md) · [专题配置格式](CONTEXT_CONFIG.md)

这里保留安装、巡查、专题、任务与费用的详细说明。首次使用可先看首页的[开始使用](../README.md#开始使用)。

## 安装

支持 **DSH Web 0.2.2-rc.1、0.2.1-rc.5 和 0.2.0-rc.2**。0.2.2-rc.1 已在 Linux、Node 24 验证安装与原生工作台；较早版本的验证范围见[实测记录](TESTED.md)。其他系统和宿主版本尚未实测。

在 DSH「插件 → 添加插件」中填写：

```text
https://github.com/KitlingKittyRabbit/dsh-whale-watch
```

启用「鲸声守望」并刷新页面，点击左侧同名入口即可使用。仓库安装获得默认分支的当前版本；需要固定版本时，可在 [Releases](https://github.com/KitlingKittyRabbit/dsh-whale-watch/releases) 下载安装包。

也可在同一输入框填写本地 `dsh-dafeiyu-patrol-0.9.1.tgz` 的绝对路径。升级按宿主提示升级或卸载旧包再安装；若仍显示旧版或入口未更新，再重启 DSH。数据保存在插件包目录之外，会继续保留。

如果安装提示“0.8.9 与 DSH 0.2.2-rc.1 不兼容”，是旧包的宿主版本范围没有包含新版 DSH，且 Cordis 运行库范围停留在 4.0.x。0.9.0 已包含 0.8.10 的兼容修复；重新安装仓库当前版本，或下载本版安装包即可，不需要添加版本豁免。更早的 0.8.8 安装限制也已修复。

安装详情若同时列出其他插件不兼容，请按插件名称分别处理。更新鲸声守望不会修复其他插件的版本限制；日志提示安装已回滚时，表示宿主已撤销本次失败的包安装。

## 第一次使用

1. 到「专题」点击 **更换专题**，选择内置 DS 拟人争议或导入自己的配置文件。
2. 到「设置」选择分析模型，默认使用 DSH 已配置的模型。想读取平台内容，再单独填写 SocialDataX 数据密钥。
3. 到「巡查」输入关键词，点击 **按篇读取并分析**。也可展开「导入原文」试用，不需要数据密钥。
4. 查看原文、配图和判断依据，看完点击 **已阅**，从未阅列表移除。原文和结果保留，可从「已阅」恢复。

默认每轮采集最多 5 篇、整篇分析最多 5 篇，数据读取额度 5 元。评论区自动分页，受额度与保护上限限制；没有读全时会标明原因。

## 三个页面

| 页面 | 用途 |
| --- | --- |
| 巡查 | 关键词读取、查看可疑内容、分析未阅、标记已阅。搜索筛选、文字导入和记录管理收在展开项中。 |
| 专题 | 更换专题、编辑资料、让 AI 制作。背景和术语统一保存，不再有独立的背景重读任务。 |
| 设置 | 数据密钥、费用额度、模型、配图读取和判断规则。 |

「搜索选项」保留接口支持的排序、发布时间、笔记类型及评论顺序。默认最新发布、时间不限、类型不限、评论综合；可保存为默认。时间范围不支持任意 N 天。多个关键词依次读取，达到本轮数量即停止，不构成跨关键词的全局热度排名。指定链接不使用笔记搜索筛选；分析未阅不会重新搜索。

「记录管理」提供“清空旧结论缓存”和“清空采集记录”，均可撤销。旧结论清理只影响当前讨论中已过期或重算失败后保留的结论；有效新结论和纯首次失败不清除。撤销不会覆盖新结果、新失败或材料已变化的记录。清空已查缓存只允许旧帖再次查找；原文和结果保留。要补采旧帖的新评论，可取消「排除已查过的笔记」。

## 搜索范围与指定用户

「读取范围」可选「笔记与评论」或「只看笔记」。只看笔记时不请求一级评论及回复接口，分析未阅和明确重算也只使用笔记标题、正文及已读取配图，不将旧评论送入模型。已有评论、判断及已阅状态保留；页面总数仍统计所有已保存记录。笔记模式点击“笔记已阅”只标记笔记，不替未看的评论标记已阅。

选择用于本轮；展开「搜索选项」点“保存搜索范围与选项为默认”可持久保存。继续任务沿用原任务范围。切回“笔记与评论”后，只读过正文的笔记仍可补采评论；早先已读过完整评论区的笔记继续遵守已查缓存，更新新评论需取消“排除已查过的笔记”。仅更新笔记不会覆盖已有评论快照。

对话巡查用 `readComments=false` 表示只看笔记，`true` 表示笔记与评论，省略沿用设置；开始巡查、分析未阅、明确重算、保存默认设置及已阅操作均支持，继续任务保留原选项。只看笔记仍可能产生笔记搜索、详情、看图及分析费用；“仅采集”则另外控制是否调用模型。旧 `maxComments` 是早期浏览器采样参数，对当前数据 API 不起开关作用。

| 填写方式 | 读取范围 |
| --- | --- |
| 只填关键词 | 使用 SocialDataX 笔记关键词搜索；标题、标签、正文的具体匹配规则由数据服务决定。 |
| 只填指定用户 | 读取这些用户发布的公开笔记，不追加默认关键词。 |
| 用户 **且** 关键词 | 先取指定用户的笔记，再读取标题、正文；包含任一关键词才继续读取评论、保存及分析。 |
| 用户 **或** 关键词 | 交替选取用户笔记和全站关键词结果，按笔记编号合并去重，共用本轮篇数和额度。 |

指定用户接受小红书完整主页链接或 24 位用户 ID，最多 5 个，每行一个。昵称和小红书号不是用户 ID；加密主页链接先由用户资料接口解析，解析也计入数据费。多个用户之间按“任一用户”，多个关键词之间按“任一关键词”；“且”模式按文字包含匹配，不区分英文大小写和全角／半角，不匹配仅存在于评论或图片识别结果中的词。

全站多个关键词按逗号或换行拆分后分别检索、合并去重；空格不拆词。单条查询内部由数据服务匹配，不承诺严格且／或。用户且关键词是完整查询字符串在标题、正文中的字面包含；正文内的 `#话题` 也会命中，不额外检索独立话题字段。

用户列表按接口返回顺序读取，不能承诺按全站点赞或时间重新排名；笔记排序只作用于关键词搜索。用户笔记的时间、图文／视频筛选在本地执行，半年按近 183 天计算，不因遇到旧置顶笔记就停止翻页。每个用户或关键词最多查找 5 页候选；达到保护上限、重复分页令牌或费用上限时保留未读完提示。达到用户设置的本轮篇数就停止，不代表覆盖所有笔记。

筛除的笔记不会读取评论或调用分析模型，但已发生的列表、正文及用户资料请求仍计费。没有匹配结果和没有读完会分别显示；更改关键词可能需要再次读取之前未保存的候选笔记。已保存篇目的去重、评论分页、模型缓存和单轮费用上限继续生效。

点“保存搜索范围与选项为默认”后，用户、关键词及且／或关系会保留；单次任务和停止后继续使用各自保存的范围。只修改当前默认设置不会改写旧任务。范围用于本次采集，下方列表仍保留已有记录，不随输入条件自动删除。填写指定笔记链接时，该输入优先，不应用用户和关键词条件；通过工具调用时不得同时传用户与指定笔记链接。

这里查的是用户**发布的笔记及这些笔记下的评论**，不是该用户在全站发表过的全部评论。

## 两个对话模式

| 模式 | 做什么 | 不同之处 |
| --- | --- | --- |
| **鲸声守望** | 通过对话操作工作台：采集、分析未阅、继续任务、重新分析整篇、查看结果和原图、标记已阅、管理记录、修改设置和专题、导出文件。 | 使用同一套后台，操作后工作台会显示相同状态。能按要求采用配置草稿。 |
| **鲸声守望配置制作助手** | 根据你提供的材料整理背景、术语和来源，校验并保存专题草稿。 | 只有资料制作工具；不能采集、分析、修改设置或直接启用草稿。 |

日常操作选择第一个；制作专题资料选择第二个。**数据商密钥仍在设置表单输入**，巡查助手可提供入口或按明确要求清除密钥，不接收聊天中的密钥。对话操作支持同样的搜索筛选和分析上限；原图每次最多返回4张，可分次查看。导出返回可下载的JSON附件。主聊天模型不支持图片时，可以在工作台查看原图。

例如对第一个说：

> 按最近一周、最多评论的顺序读取3篇，只采集，暂不分析。
>
> 分析未阅篇目；停止后继续剩余工作，不重算已有结果。
>
> 查看配置制作助手保存的草稿，采用它。把当前专题导出给我。

采集、分析、重新分析及继续任务的费用规则与工作台一致。专题切换、修改设置和保存文件不启动分析；旧结论不会自动重算。

## 专题资料

专题文件包含 **背景说明、来源、术语与别名、适用语境及未确认解释**。它解释原文的含义；具体行为是否不合理仍由「设置」中的规则判断。

- **更换专题**：使用内置 DS 配置，或选择 JSON 文件。选择后自动检查并载入，错误用中文说明。
- **编辑资料**：用普通表单修改背景、术语和用法说明，点击「保存资料」。保留本机来源原文和旧分析。
- **让 AI 制作**：打开配置制作助手的新对话。提供材料和要求，助手整理并保存草稿；回专题页查看，点击 **采用这份配置**。
- **更多**：导出专题、撤销上次修改、卸下专题。

文件保存和导入不调用模型。助手对话使用当前模型，可能计费；不会自行采集或启用草稿。换专题、修改资料不会自动重算旧结论；普通分析只处理未分析和失败项。需要更新旧结论时，手动「重新分析整篇」。

内置 DS 配置包含此前整理的 36 篇背景来源、7 个术语及 4 段语境说明，保留来源说法和不确定性。使用它不重新访问原帖。已有安装沿用原来的背景与术语，新安装需要主动选择专题。

分享时导出的是背景摘要和术语配置，不包含采集列表、完整原帖、图片、模型凭据或数据密钥。文件不能指定插件代码、模型或预算。详细格式见 [专题配置指南](CONTEXT_CONFIG.md)。

DS争议当前最重要的识别目标：**不光要找肥鱼方冲锋的，伪装理中客的藤壶方也要识别。** 其余沿用已有判断规则，没有追加新的身份推断标准。已有安装按自己的要求编辑当前判断规则和专题资料；升级不会自动覆盖。

## 分析结果与继续任务

「可疑」是有具体依据、值得人查看的内容；「其它」包括正常讨论和暂时无法确定的内容，原因中会说明局限。程序检查通过不等于真实语义判断准确。

同时显示 **篇数和条目数**：一条指正文或一条评论；一篇可以同时包含可疑、其它和待分析条目，因此分类篇数不互斥。正文与已保存评论合并提供语境，篇内分批输出判断，疑似问题另核对证据。

停止后点击「继续分析剩余篇目」，或「分析未阅篇目」处理下一批。已有成功结论不会自动重算；失败项保留错误并可重试。材料、规则或模型变化后显示旧结论提示；明确重新分析整篇才会重算已有结果。

模型输入包含目标原文、上下文、当前专题及相关来源；配图启用时另由看图模型读取文字和画面。漏图、模糊和看图失败会保留提示。**视频画面和音频不识别。**

## 数据 API 与费用

数据采集使用 [SocialDataX](https://socialdatax.com/ai/) 第三方服务，**不是小红书官方接口**。浏览器自动采集、自动登录和浏览器跳转接口已停用。没有数据密钥时，可导入原文或分析本机已有记录。

不向数据商提交小红书密码或 Cookie；供应商接收搜索词、笔记链接/编号和分页请求。接口可能缺少隐藏、删除或未返回的评论，服务覆盖与授权状态由供应商决定。

按接入时的价格，搜索、详情、每页评论或回复约 0.10 元/次，实际页大小由服务返回。默认 5 元额度限制最多 50 次请求尝试；连接失败占名额，不自动重试。界面显示已确认费用和待确认次数。发现返回单价变化时停止后续请求，已经发出的请求可能按新价收费，因此不能保证供应商改价后仍不超额。

**数据费用与大模型、看图费用分开。** 分析篇数上限不是模型金额预算；评论多的篇目会有多批调用，失败调用也可能收费。首次建议勾选「仅采集」核对材料，再分析未阅。

## 数据保存

默认保存在 `~/.dsh/dafeiyu-patrol/`；设置 `DSH_HOME` 时位于其下的 `dafeiyu-patrol/`。

`state.json` 保存原文、结果、已阅、专题和任务。数据密钥单独保存在权限 0600 的 `socialdatax-key.json`，是本机明文，不进入模型材料或导出。原图由宿主附件服务存储；导出记录不包含图片字节。旧浏览器登录目录不再使用。

不要分享或提交上述私人数据目录。待分析文字、背景及配图会发送到你选择的模型服务。
