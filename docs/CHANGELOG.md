# 版本更新

[返回首页](../README.md) · [使用手册](USAGE.md) · [全部发布版本](https://github.com/KitlingKittyRabbit/dsh-whale-watch/releases)

这里记录近期版本的具体变化，较早版本见 GitHub Releases。

## 0.8.8

新增：在“巡查 → 记录管理”清空旧结论缓存，可撤销。只清除标为旧结论的分析，保留原文、配图、识图缓存、已阅状态及有效新结论；清理不调用模型。清理后的未阅条目回到待分析，再点“分析未阅篇目”才会重新分析，模型费用另计。

## 0.8.7

修复：值班台插画随样式表一起交付，避免升级后运行中的旧服务无法识别新图片地址；修复玻璃皮肤覆盖页头背景、导致浅字看不清的问题。横幅重绘为完整房间并等比铺满，标题放入紧凑半透明信息牌；原图保留为设计源文件，运行图片约317KB。

## 0.8.6

修复：显式重新分析整篇时，重读之前不完整的配图识别结果；普通续跑及完整图片结果继续复用，避免重复看图费用。手动导入和未知来源不再被标成旧版浏览器采样；看图额度说明与实际 32,768 token 上限一致。

## 0.8.5

修复：沿用已保存的看图额度；整篇分析单列每个目标原文，并使用本批短编号返回结果，避免混淆平台编号和本机记录编号；引文校验失败时最多单独修复一次，仍不符就保留失败；证据核对使用独立的三分钟和 32,768 token 回复上限；看图统一使用三分钟和 32,768 token 回复上限，明确读取评论自身的配图；明确重算整篇时，尝试补回原先下载失败的已保存图片链接，不重新查询数据 API；补充数据接口实际返回的 `sns-i数字.rednotecdn.com` 图片域名。未放宽证据校验，也未改变专题中的识别目标。已有判断不会自动重算；明确重算整篇后中途停止，再继续时保留本次剩余目标，旧结论不会让未完成的重算被跳过。

引文修复会额外调用模型一次并写入任务日志；证据核对和看图也产生模型费用，费用由当前模型服务计算，数据 API 的费用上限不包含模型费。

模型服务异常会显示错误码和 HTTP 状态（服务有提供时），不显示可能含敏感信息的原始响应。任务“部分完成”的具体原因请看详情；图片有模糊或裁切，也可能出现该状态，不等于还有条目分析失败。
