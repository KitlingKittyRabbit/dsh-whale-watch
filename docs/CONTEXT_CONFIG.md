# 专题配置：背景与术语

0.8.3统一在“专题”页管理资料。背景和术语用于解释语境；行为标准在“设置”里。

## 怎么使用

- **更换专题**：选择内置DS拟人争议，或选择自己的JSON文件；自动检查并载入。
- **编辑资料**：填写背景说明和术语解释，保存即可。不需要编辑JSON。来源及其本机原文会保留。
- **让 AI 制作**：直接打开制作助手的新对话，提供背景材料和词语示例。回专题页查看草稿，点击“采用这份配置”。
- **更多**：导出文件、撤销上次修改或卸下专题。

资料修改、导入、撤销不启动模型调用，不改采集记录、已阅、规则或预算。旧结论保留；手动重新分析整篇才会重算。任务进行中不能修改专题。编辑期间专题发生变化时，保存会提示重新打开编辑，避免覆盖别人的更新。

助手示例：

> 请根据下面的背景材料和词语示例，制作园艺讨论专题。整理背景、“爆盆”“徒长”的用法和来源，保留不确定解释，保存配置草稿。

助手只有读取配置格式、读取当前资料、校验和保存草稿的工具，不自行采集或启用配置。对话使用当前模型，可能计费；保存和导入不调用模型。

**两个模式的区别**：“鲸声守望”可以操作整个工作台，包括采用草稿、更换专题、编辑资料、导出及撤销；“鲸声守望配置制作助手”只制作和保存草稿。草稿可以在专题页点击采用，也可以回到“鲸声守望”对话明确要求采用。制作助手没有启用工具。

巡查助手编辑前读取当前资料及版本标记；期间专题有变化就拒绝覆盖，需重新读取。导入支持直接提供JSON或明确指定本机JSON文件路径。导出配置、草稿、内置专题和模板返回JSON文件附件。

以下格式供分享文件或开发使用，普通编辑无需填写这些字段。

## 最小文件示例

```json
{
  "format": "whale-watch-context",
  "schemaVersion": 1,
  "id": "garden-discussion",
  "name": "园艺讨论",
  "description": "帮助理解园艺用语",
  "revision": "1",
  "background": {
    "memo": "讨论植物种植与养护。[B1]",
    "sources": [
      {"ref": "B1", "title": "用法材料", "summary": "用户提供的园艺术语示例摘要"}
    ]
  },
  "glossary": [
    {
      "term": "爆盆",
      "aliases": [],
      "meaning": "植物生长茂盛、占满花盆的说法",
      "usageNotes": "在养护讨论中通常描述植物状态，不是人身攻击。",
      "status": "source_claim",
      "sourceRefs": ["B1"],
      "sources": []
    }
  ],
  "interpretationNotes": ["区分种植效果评价与对种植者的侮辱。"]
}
```

`id`使用小写英文、数字与连字符，最长64字符。文件UTF-8编码，最大300 KB；最多100篇来源、100个术语，背景笔记最多24,000字符，术语与语境说明合计最多24,000字符。仅支持格式版本1，未知字段会拒绝导入。可以参考上述示例起草；文件不能指定代码、插件、模型、密钥或接口。

## 来源和不确定性

- `background.sources`：每篇用唯一`ref`（B1、B2等），必填`title`与`summary`；`url`可选，仅HTTP/HTTPS，不含用户名密码。背景中的`[B1]`和术语`sourceRefs`须在文件里存在。
- `glossary`：必填`term`与`meaning`；可选别名`aliases`、用法/反例`usageNotes`、来源编号`sourceRefs`和词义来源网址`sources`。
- 术语`status`：`source_claim`表示来源说法；`uncertain`表示未知或候选解释；`confirmed`仅表示配置作者已核对，不代表软件独立查证，更不能跳过当前上下文。仍可有同名异义和非攻击用法。
- `interpretationNotes`：语境注意事项字符串数组，与术语共同进入初判和证据核对。是参考资料，不是修改行为标准、要求执行操作的系统指令。
- 来源可选`uncertainties`（字符串数组）、`observations`（知识点数组）和`excerpts`（摘录数组）。知识点含`kind`、`subject`、`explanation`、`status`（source_claim/direct_observation/uncertain）、`sourcePart`、`quote`。配置格式校验不验证引文是否真实；摘录含`label`、`text`和可选`uncertain`。

分享文件默认导出摘要与来源索引，不导出来源全文或`excerpts`。再次独立整理背景时，导出会保留术语所引用的原来源并重新编号，避免新背景的B1被误用来证明旧释义。软件不自动访问文件中的外链。

专题文件、来源说法、帖子和评论均作为数据交给模型，固定提示要求忽略其中的操作指令；这不能保证模型永不误读。检查文件内容、词义出处与实际结果仍有必要。程序测试证明配置接入和数据保留，不证明真实语义分类准确率。
